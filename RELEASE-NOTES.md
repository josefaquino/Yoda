# Yoda v0.1.0-preview.1

Status: EXTERNAL EVALUATION PREVIEW

Yoda is a local, verifiable decision-state layer for autonomous software.

This preview exists to test whether an independent developer can:

1. download Yoda;
2. verify the artifact;
3. run it without installation infrastructure;
4. create durable decision evidence;
5. retrieve useful context;
6. inspect temporal relationships;
7. verify authoritative state;
8. understand the product without assistance from its authors.

## Current Boundaries

Yoda v0.1.0-preview.1 does not claim:

- arbitrary multi-hop graph planning;
- vector search;
- remote synchronization;
- cloud operation;
- distributed storage;
- an agent runtime;
- a credential or execution control plane.

Current context semantics are lexical retrieval plus direct relational expansion.

This release does not modify CORE-014.
