# A1-R2 - Representation-only deterministic classification

## Status

```text
STATUS=PRE-REGISTERED
EXECUTED=NO
EXECUTION_POLICY=ONE_EXECUTION
```

## Why R2 exists

A1-R1 remains:

```text
A1_R1=NOT_EVALUATED
ROOT_CAUSE_CLASS=NUMERIC_REPRESENTATION_CONTRACT_MISMATCH
A1_R1_RERUN=NO
```

All three frozen NFCI inputs contain five fractional digits. The v1 authority admitted at most four.

A1-R2 changes numeric representation capacity only.

Before the A1-R2 lock is consumed:

```text

FIXED5_INPUT_COMPATIBILITY=PASS
```

If this does not pass, A1-R2 must not start.
