## Why history is preserved

Yoda's research program treats negative results and superseded mechanisms as evidence.

The same principle applies to repository history.

```text
prototype
↓
experiment
↓
failure or discovery
↓
architectural decision
↓
current system
```

Deleting historical repositories would destroy part of that provenance.

Therefore the repository policy is:

```text
Yoda
-> active canonical repository

Historical predecessors
-> preserved, archived when possible

Evidence
-> never deleted merely because a later design replaced it
```
